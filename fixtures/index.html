form-keeper fixtures

Fill a form, reload, and the values should come back. Each page shows the framework's own state so you can see it was updated, not just the DOM.

  • Plain HTML form (every field type, plus fields that must never be saved)
  • React controlled form (renders after 400 ms; after 6 s)
  • Vue form (v-model)
  • Svelte 5 form (bind:)
  • UI library widgets (react-select, Ant Design, MUI, Radix, Headless UI, react-datepicker, rich text)
  • Custom controls (non-standard dropdowns that need teach mode)
  • File inputs (single, multiple and a hidden input behind a styled button)
  • Svelte widgets (svelte-select and a button chip group)
  • Single-page app (client-side routes, one saved form per URL)
